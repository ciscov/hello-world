# Homework Tracker

A simple homework list for a high school student. It's one HTML file with no server and no account,
and data is saved in the browser.

## Use it
- Open `index.html` in a browser, or host it with GitHub Pages and open the link on a phone.
  Then use **Share → Add to Home Screen** so it works like an app.
- **Import from Campus**: copy the assignment list from the Campus app or website (Today or Grades view),
  paste it, check the preview, and tap **Add**. Re-importing the same list skips items already added.
- It also reads CSV/TSV with `class, assignment, due` columns, and one-line entries like
  `Chemistry: Worksheet due 11/18`.
- Tap an assignment to edit it or add notes. Check the box when it's done.
- **⋯ → Save backup file** exports everything as JSON. Data is stored only on that device.
